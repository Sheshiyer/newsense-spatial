# Newsense Narrative Scene Map

Date: `2026-05-13`

## Purpose

Translate the Newsense brand idea into a spatial storytelling model that can be
implemented inside the `false-earth` runtime.

## Name Thesis

`Newsense` should be read as:

- new sense
- new perception
- new signal
- clearer discernment

Its implicit contrast is:

- nuisance
- noise
- clutter
- repetition without meaning

The world must dramatize this transition.

## Story Spine

The entire site should move through this emotional and editorial sequence:

1. drift
2. threshold
3. orientation
4. signal field
5. focus
6. interpretation
7. invitation

## World Translation

### Drift

Inherited from the original `false-earth` energy:

- distance
- atmosphere
- scale

But in Newsense this is only the precondition, not the destination.

### Threshold

The first Newsense act is a stable encounter.

The user should feel:

- they have left noise behind
- they have reached a surface that can be read

### Orientation

The preserved wordmark and calm architectural mass establish:

- identity
- seriousness
- navigable order

### Signal Field

Projects do not appear as a random field of media.

They resolve into grouped constellations that the user can read at a glance.

### Focus

Opening a project should feel like bringing one signal into sharp resolution.

### Interpretation

The studio and team routes explain the method behind the clarity.

### Invitation

`Contact` is not a generic CTA page. It is the moment where the visitor is
asked whether they want to enter that same process of clarification.

## State Map

Shared story-state vocabulary:

- `idle`
- `focus`
- `open`
- `return`

### `idle`

World meaning:

- atmosphere before interpretation

### `focus`

World meaning:

- one signal is being isolated

### `open`

World meaning:

- interpretation becomes readable content

### `return`

World meaning:

- coherence is preserved while backing out to the larger field

## Interaction Consequence

The world must not reward wandering for its own sake.

The interaction should feel like:

- selecting
- clarifying
- reading
- resolving

Not:

- roaming
- collecting
- winning
- mastering a game system

## Copy Consequence

Homepage and supporting copy should reinforce:

- coherence
- precision
- seeing better
- bringing ideas to life with structure and resonance

Avoid:

- generic agency slogans
- technology-first chest-thumping
- vague luxury language detached from meaning
