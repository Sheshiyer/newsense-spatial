## Core Decision

The homepage anchor is a **wordmark monolith**, but not a logo sculpture.

It is an architectural object made from calm rectilinear masses that frame the
preserved `newsense` wordmark as a stable orientation surface.

It should read as:

- a threshold
- a stage
- an addressable architectural face

It should not read as:

- a symbolic totem
- a giant prop
- a literal product object
- a warped 3D logo

## Role In The Experience

The monolith is the first spatial statement on `/`.

It must do four jobs:

1. orient the user immediately
2. hold the preserved wordmark with authority
3. establish the material language for the whole site
4. open first-intent paths into `Projects`, `Studio`, and `Contact`

This is the calmest object in the whole system.

`Projects` becomes more active after the first intent. The monolith stays the
grounding surface.

## Object Thesis

Think of the monolith as a **built facade fragment**:

- one dominant pale stone plane
- one darker recessed body
- one oxidized bronze spine or flank
- one smoked-glass threshold element

The object should suggest depth, interiority, and editorial restraint without
becoming a literal building model.

## Form Definition

### Primary Mass

- large vertical slab
- off-center in the frame
- pale mineral or matte stone finish
- broad uninterrupted face

### Secondary Body

- darker recessed volume
- creates depth shadow and negative space
- supports the sense of threshold

### Bronze Element

- narrower vertical accent
- oxidized or brushed bronze
- provides warmth and premium tension

### Glass Element

- low smoked-glass guard or vestibule plane
- clarifies scale and contemporary studio tone

## Wordmark Treatment

The preserved wordmark remains a **2D identity layer** applied to the object
system, not generated by the object system.

Allowed treatments:

- frontal signage plane
- etched or printed surface on a flat face
- quiet overlay in scene/UI composition

Not allowed:

- wrapping across corners
- curving over geometry
- extrusion into unreadable mass
- splitting into separate letters in space
- glowing logo gimmicks

Rule:

- the scene frames the mark
- the mark does not become the sculpture

## Material System

Primary materials:

- pale mineral stone
- near-black matte structure
- oxidized bronze
- smoked glass

Secondary supporting materials:

- dark paper
- brushed metal
- soft diffused reflection

Disallowed additions:

- saturated accent colors
- glossy chrome futurism
- rough fantasy ruins
- ornamental temple relief carryover

## Scene Placement

### Default Placement

- object occupies the center-right weight of the stage
- wordmark remains top-left in the interface field
- negative space is preserved on the left for thesis copy and first-intent CTA

### Horizon Behavior

- low horizon
- strong ground reflection but not mirror-polished spectacle
- atmosphere should feel still and heavy, not fog-machine theatrical

## Interaction Contract

### Idle

- object holds position
- minor atmospheric drift only
- no gimmick rotation

### Focus

- camera advances slightly and lowers lateral ambiguity
- bronze and shadow edges gain definition

### Open

- scene reveals linked pathways or overlay transitions into:
  - `/projects`
  - `/studio`
  - `/contact`

### Return

- object regains its calm frontal authority

## Camera Guidance

This object needs deliberate camera rules later in `NS-702`, but the anchor
spec already freezes the posture:

- no orbit-demo behavior
- no game-follow behavior
- no extreme parallax as the main trick

Preferred camera language:

- slow dolly
- slight lateral drift
- heavy-to-light reveal
- precise stop points

## Content Relationship

The object may sit beside small supporting text, but the homepage must not
collapse into a dense editorial hero.

Allowed adjacent content:

- one short positioning block
- one small first-intent action group
- quiet route labels

Not allowed:

- giant manifesto paragraphs over the object
- dense deck-like annotation across the frame

## Runtime Variants

### `immersive`

- full object with layered materials and subtle depth
- smoked-glass plane retained
- controlled lighting and ground reflection

### `reduced3d`

- fewer material layers
- simplified reflection
- flatter shadow behavior
- object remains architecturally legible

### `editorial`

- DOM-first hero using the same composition logic:
  - preserved wordmark
  - one large rectilinear architectural image/render
  - concise first-intent copy

Editorial fallback must preserve the thesis even if the scene disappears.

## Meshy Relationship

Meshy may help generate surrounding support objects derived from this language:

- plinth segments
- frame blocks
- bronze side pieces
- smoked-glass accessory volumes

Meshy must not generate the wordmark itself.

## Acceptance For NS-902

- The homepage anchor is decisively architectural, not symbolic-prop-driven.
- The wordmark stays a preserved identity layer, not a distorted 3D artifact.
- The object can degrade across `immersive`, `reduced3d`, and `editorial`
  modes without losing orientation value.
